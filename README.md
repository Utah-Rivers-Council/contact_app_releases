# URC Sign-Up releases

Release repo for URC Sign-Up app.

- **[Download the latest APK](https://github.com/Utah-Rivers-Council/contact_app_releases/releases/latest/download/urc-signup.apk)**
- [Latest release notes](https://github.com/Utah-Rivers-Council/contact_app_releases/releases/latest)
- [All releases](https://github.com/Utah-Rivers-Council/contact_app_releases/releases)

Each release has the signed APK, `urc-signup.apk`, under **Assets**, and a `version.json` describing it. It installs over the existing app and keeps saved sign-ups.

This repo holds no source code or sign-up data.
